# Varshith Reddy | AI/ML Engineer & SDE Portfolio

An anime-themed, interactive developer portfolio fusing **Blue Lock (Egoist Metavision)** and **Demon Slayer (Hinokami Breathing)** aesthetics. Built with modern Vanilla web standards, ready for immediate hosting on **GitHub Pages**.

🔗 **Live Portfolio URL:** [https://varshith0810.github.io/](https://varshith0810.github.io/)

---

## ⚡ Core Features

- **Dual-Domain Theme Switcher**:
  - **Blue Lock Mode (Egoist)**: Electric cyan `#00f0ff`, Metavision violet, floating puzzle piece animations, spatial network grid, and tactical HUD evaluation ranks.
  - **Demon Slayer Mode (Hinokami Kagura)**: Sun Breathing flames, Nichirin blade slashes, water breathing trails, Tanjiro checkered accents, and calligraphy titles.
- **Interactive 60fps Canvas Particle Engine**:
  - Dynamic puzzle shard magnetism and Metavision target reticle in Blue Lock mode.
  - Fluid cursor blade slash ribbon and rising flame embers in Demon Slayer mode.
- **Synthesized Web Audio SFX Engine**:
  - Procedural anime sound effects generated purely using the browser's native **Web Audio API** (katana unsheathe, Metavision hum, puzzle clicks, awakening explosions) with a sound toggle. Zero missing audio links!
- **Tactical Evaluation HUD**:
  - Real-time animated status bars and power ranking metrics for AI/ML, Distributed Systems, LeetCode/DSA, and High-Throughput APIs.
- **Interactive Technical Arsenal (Skills)**:
  - Categorized skill trees with pointer spotlight reveals and animated filtering.
- **3D Tilt Project Cards**:
  - Holographic perspective cards with live GitHub links and architectural breakdowns.
- **Interactive CLI Terminal**:
  - Functional terminal with commands (`help`, `about`, `skills`, `projects`, `contact`, `hire`, `theme`, `awaken`, `clear`).
- **100% Native GitHub Pages Compatibility**:
  - Pure HTML5, CSS3 (with registered `@property` tokens and glassmorphism), and modular ES6 JavaScript. No bundlers or build steps required.

## 🚀 How to Host on GitHub Pages

1. **Commit and Push to GitHub**:
   ```bash
   git add .
   git commit -m "feat: initial release of Blue Lock x Demon Slayer portfolio"
   git push origin main
   ```
2. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/varshith0810/varshithreddy.github.io`
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment**, select **Deploy from a branch**.
   - Select Branch: `main` and Folder: `/ (root)`.
   - Click **Save**.
   Your site will be live across the world at `https://varshithreddy.github.io`!
